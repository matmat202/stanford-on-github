Stanford on GitHub

Every public repo from the GitHub organisations of Stanford's labs, courses and student groups, ranked.

      Every group, by total stars
      Data: the GitHub API, fetched . A group is here if its organisation profile says Stanford (in its name, description, website, email or location), plus one lab added by hand because its profile doesn't: tatsu-lab, Tatsunori Hashimoto's group, home of Stanford Alpaca. That is self-description, not verification, and code that Stanford people publish under personal accounts is not here. Forks are left out, as are repos under 3 stars. "Good first issues" are open issues labelled good first issue or help wanted, fetched , in the repos listed here, leaving out any already assigned to someone; check the issue itself before starting, since it may have been picked up since. "Course" and "club" are read from each profile's wording and can be wrong. Built by Claude for matmat202. Not affiliated with Stanford University or GitHub.
