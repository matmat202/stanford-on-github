Stanford on GitHub · a story

Most code goes quiet

Stanford's labs, courses and student groups keep GitHub organisations with code of their own in them: repositories, not counting forks. Each dot here is one of them. This story follows what happened to them after they were made.

Chapter 3 · Who noticed

The starless ones stop first

A star on GitHub is a bookmark: someone found the repo and wanted it back. Nearly half of these repos never get even one. Gold here is three stars or more.
